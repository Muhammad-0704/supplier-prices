# Общий стиль Базы

Основа до редизайна: локальный тег `backup/pre-redesign-2026-11-13`, коммит `3687308`.
Рабочая ветка: `redesign/shared-style`.

## Источники

- [shadcn/ui Neutral](https://ui.shadcn.com/docs/theming): нейтральные поверхности, текст, границы и состояния элементов управления.
- [ObsidianUI Dashboard Shell](https://www.obsidianui.dev/docs/dashboard-shell): официальный блок из `https://obsidianui.dev/r/dashboard-shell.json`, локальные исходники в `src/components/block/`.
- Кнопка shadcn/ui: `src/components/ui/button.tsx`.
- Inter Variable поставляется локально через `@fontsource-variable/inter`, включая кириллицу. Внешний запрос к Google Fonts не нужен.

## Правила

Навигация, заголовки, кнопки и карточки используют нейтральную палитру в обеих темах. Синий `series-1` обозначает основной ряд графика, `series-2` — сравниваемый показатель. Цвет легенды должен совпадать с рядом. Зелёный и красный сохраняют смысл лучших цен, изменения цены и статусов; фудкост использует существующие бизнес-пороги.

Общие цвета и шрифты редактируются в `design/tokens.json`. Затем выполнить `npm run tokens`. Адаптация Dashboard Shell к этим токенам находится в `src/app/workspace.css`. Tailwind применяется к импортированным компонентам, без глобального Preflight; сброс стилей кнопок ограничен их `data-slot`.

`WorkspaceShell` используется главной страницей, Прайс-доской, заявкой, предложениями, настройками и страницами Центра Питания. Серверные обёртки передают навигацию по доступной роли. У узкого окна меню открывается поверх содержимого, блокирует фон, удерживает фокус и закрывается по Escape. Экран входа использует те же токены и переключатель темы. ТВ сохраняет собственную раскладку.

Адаптации официального блока: `forwardRef` для React 18, управление `inert` через DOM, поддержка `data-theme`, русские подписи кнопок. Middleware передаёт CSP в заголовки запроса для nonce скриптов Next.js; `unsafe-eval` разрешён исключительно при `NODE_ENV=development`.

## Проверка

Для проверки без доступа к базе использовать временную страницу под `/login-…`, как описано в `CLAUDE.md`, с настоящими компонентами и тестовыми записями. Удалять её перед коммитом. На тестовых данных проверены Прайс-доска, сводка столовых и вход: 1440 × 1000, 390 × 844, светлая и тёмная темы, сохранение темы, переходы, поиск, изменение ширины меню с клавиатуры, Escape и возврат фокуса. Рабочая авторизация и операции с реальной базой требуют отдельной приёмки с доступом.

Обязательные проверки: `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`. Схема, RLS, формулы расчётов и интеграции этим редизайном не меняются.
